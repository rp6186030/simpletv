# TCL 55" 4K Google TV, 2023 model year, US (device G10, product G10_4K_US_NF, Realtek RTD2875P)
# Android 12 (Google TV, basic mode), firmware STT2.230203.001, software V8-R75PT01-LF1V499
# Likely a good starting point for other 2023+ TCL Google TV sets on the Realtek G10 platform.
#
# Apply:   TV_HOST=<tv ip> tools/disable.sh examples/tcl-g10-google-tv/debloat.txt
# Undo:    TV_HOST=<tv ip> tools/restore.sh examples/tcl-g10-google-tv/debloat.txt com.google.android.apps.tv.launcherx
# Everything is DISABLED, not uninstalled. Comment out any line you want to keep.
#
# Stock launcher: com.google.android.apps.tv.launcherx (pass it to restore.sh, the default is wrong here).
# Live TV app: com.tcl.tv (keep it, it also owns HDMI/antenna playback). Keep com.tcl.tvinput,
# com.tcl.dashboard, com.tcl.suspension, com.tcl.autopair and com.tcl.systemserver too.
# Already disabled at the factory: com.tcl.logkit, tv.samba.ssm.ui (Samba TV ACR), com.tcl.ttvs.
#
# Known quirks on this firmware:
# - The red "TV" tile disappears from the Google TV Home row after this list (probably
#   com.tcl.partnercustomizer). TV stays in the Apps row and behind the Inputs tile.
# - Disabling dreamx leaves screensaver_components pointing at it. Switch to the AOSP fallback with
#   tools/tv.py 'settings put secure screensaver_components com.android.dreams.basic/.Colors'
# - screencap writes an empty file while Live TV/HDMI is on screen. Press Home first.
# - The Google TV promo banner is drawn by launcherx itself, so only launcher/ removes it.
# - Making Claude TV the Home screen needs TWO packages disabled, not only launcherx. Observed on
#   this firmware (STT2.230203.001, retested on a TCL G10 in 2026): with only launcherx disabled the
#   Home key opens com.google.android.tungsten.setupwraith/.RecoveryActivity instead, even though
#   Claude TV holds the HOME role and set-home-activity returned Success. Re-running set-home-activity
#   did not help, and the shell cannot disable RecoveryActivity alone (SecurityException).
#   Disabling both packages (one pm call each) made Home and the Home key open Claude TV and it
#   survived a reboot:
#     tools/tv.py 'pm disable-user --user 0 com.google.android.apps.tv.launcherx'
#     tools/tv.py 'pm disable-user --user 0 com.google.android.tungsten.setupwraith'
#   setupwraith is the Google TV setup wizard (guest reset, add account, remote re-pairing). Neither
#   package is in this list, so restore.sh does not re-enable setupwraith: undo it by hand with
#     tools/tv.py 'pm enable com.google.android.tungsten.setupwraith'
#   Re-enable it before a factory reset or pairing a new remote. Reports for other Google TV devices
#   say the YouTube remote button may stop working once the stock launcher is disabled; on this
#   TCL G10 it still opened YouTube. Try launcherx alone first if you prefer; if Home opens a recovery screen,
#   re-enable launcherx at once (pm enable) and use both. One TV dropped off Wi-Fi right after the
#   second disable and was reconnected by hand; the cause was not established. Disable these only
#   after confirming Claude TV launches (am start -n com.gathin.tvhome/.MainActivity). A system
#   update may re-enable them, so check that Home still opens Claude TV afterwards.
